Tinycast automation protocol

Question: can one Tinycast command set serve four callers at once, each with its own trust level? The callers are a tinycast:// link opened by any app, an agent over MCP, a script Tinycast runs, and the tinycast CLI. It borrows Script Kit's resource namespace, scoped tokens, audit log and script prompts over JSON lines, and BTT's localhost server, fire-and-forget links, stdio bridge CLI and Allow/Deny prompt. Everything here is simulated in memory. Nothing talks to Tinycast.
